Trusted Publisher Management

OpenID Connect (OIDC) provides a flexible, credential-free mechanism for delegating publishing authority for a PyPI package to a trusted third party service, like GitHub Actions.

PyPI users and projects can use trusted publishers to automate their release processes, without needing to use API tokens or passwords.

You can read more about trusted publishers and how to use them here.

Add a new pending publisher

You can use this page to register "pending" trusted publishers.

These publishers behave similarly to trusted publishers registered against specific projects, except that they allow users to create the project if it doesn't already exist. Once the project is created, the "pending" publisher becomes an ordinary trusted publisher. You can read more about "pending" and ordinary trusted publishers here.

Configuring a "pending" publisher for a project name does not reserve that name. Until the project is created, any other user may create it, including via their own "pending" publisher.
