# quiverlab v0.2.0 — Release metaplan (Plans 36–50)

**Date:** 2026-08-05 · **Status:** approved design (Marco, brainstorm session
2026-08-05) · **Trunk:** `dev` (fast-forwarded to `main`@5e16b8d, the v0.1.0

coverage program (ROADMAP.md) and land the five research axes Marco named:
Macaulay2 oracle, spectral sequences, derived categories, Coxeter polynomials,

This document is the metaplan. Each subplan below (P36–P50) becomes its own

## 1. Scope decisions (Marco, 2026-08-05)

1. **Scope = everything:** the five axes PLUS the full remaining C1–C8 coverage
   program, one release (v0.2.0), ~15 subplans.
2. **Coxeter axis scaled back by choice:** ship the classical Coxeter
   matrix/polynomial as exact Cartan-derived invariants only. The
   Tamarkin–Tsygan-automorphism machinery of arXiv:2606.15595 (σ_A on the
   calculus), per-HH-degree "higher Coxeter polynomials" (found to be
   literature white space — *nobody* has defined them), and τ-Hochschild
   (arXiv:2607.10913) are **deferred** to the backlog (§8).
3. **Spectral-sequence presets — all four:** Cartan–Eilenberg change-of-rings,
   Grothendieck (general, two bimodules via Eilenberg–Watts), associated-graded
   ⇒ Ext (Anick/deformation), Hochschild (b,B) double complex. Custom filtered
   / double complexes always included.
4. **Decomposition shape = foundation-first waves** (dependency-ordered
   capability units, maximal parallelism), not axis-first or serial-coverage.

## 2. Research grounding (2026-08-05 briefs, five parallel agents)

Condensed; the load-bearing facts each subplan must respect.

**Marco's paper (arXiv:2606.15595).** σ_A = automorphism of the TT calculus
induced by the AR bimodule DA[−1]; on HH_• its matrix (elementary case, trace
basis) is −C⁻¹Cᵀ with char poly = Coxeter polynomial; on HH^• it is the
identity (recovers Suárez-Álvarez). Worked oracles with exact numbers: D₄ vs A₄
(φ = x⁴+x³+x+1 vs x⁴+x³+x²+x+1 — same TT calculus, distinguished by φ), the
8-vertex cospectral trees (equal φ = (x+1)⁴(x⁴−3x³+x²−3x+1), not derived
equivalent). Follow-ups: arXiv:2607.10913 (τ-Hochschild); arXiv:2509.12984
(Chen–Ruan–Yang TT computation paper — candidate external oracle, needs a
human read). All deferred except the Coxeter polynomial itself (P38).

**Macaulay2.** Genuine independent oracle for: (a) single-vertex graded kQ/I
over GF(p) — `AssociativeAlgebras` nc Gröbner (`NCGB`, F4 over GF(p)),
`ncBasis`, dimension, `ncHilbertSeries`; (b) commutative examples — core
`Ext`/`Tor`, `Complexes` `freeResolution`+`betti` (`LengthLimit` mandatory over
Artinian rings), `DGAlgebras` (`acyclicClosure`, `deviations`→Poincaré series,
`isGolod`). **No quiver/idempotent type, no Hochschild, `extAlgebra` is
commutative-residue-field-only** — multi-vertex HH stays QPA + theory.
Interop: long-lived `M2 --script` process, sentinel-delimited stdout (same
shape as the QPA bridge), brew/apt install, pin the version
(AssociativeAlgebras is flagged "interface will change"). Design mining for
us: `Complexes` `.dd`/`LengthLimit` ergonomics, the ASCII `betti` grid, the
`SpectralSequences` page API (`E^r_{p,q}`, `netPage`, `spots`).

**Spectral sequences.** All computable on `fields.linalg`: Z_r/B_r subquotient
formulas (Weibel §5.4), d_r by lift-apply-reduce, canonical bases via
`reduce_mod_nullspace`. Bounded filtration of a bounded complex ⇒ strong
convergence automatic, E_∞ reached by page max(width,height)+1, degeneration
at E_r decidable by rank (dimension comparison of consecutive pages).
Grothendieck-over-module-categories framing **confirmed** (homalg implements
exactly this; Barakat arXiv:0904.0240): F, G given by bimodules
(Eilenberg–Watts), acyclicity hypothesis checked per instance, refused loudly
otherwise. Free oracles: Happel one-point-extension LES (arXiv:0707.3210
reads it off change-of-rings), SBI rank identities on HH/HC dims we already
compute, Ext_gr ⇒ Ext degeneration ⇔ Koszul (vs Plan-27 verdict), closed-form
k[x]/(x^a), M2 `SpectralSequences` on commutative cases. Prior art: M2,
homalg, Kenzo (Romero–Rubio–Sergeraert JSC 2006), the `ext`/`sseq` Adams
tooling. ("ISH spectral sequence" could not be verified as standard — do not
cite.)

**Derived categories.** QPA Ch. 10–11 already has complexes, `MappingCone`,
`HomologyOfComplex`, `ProjectiveResolutionOfComplex`, `TauOfComplex` — those
are cross-oracles. White space we add: Hom_{D^b}(X,Y[n]) = hyper-Ext via the
Hom double complex; derived-iso test (cone acyclicity); tilting-complex
verifier (rigidity + K₀ generation, det ±1); **End(T) as an algebra** (derived
equivalent algebra, Rickard); 2-term silting ↔ τ-tilting (AIR). Happel: Serre
functor/AR triangles exist **iff gl.dim < ∞** (τ_{D^b} = ν∘[−1]); refuse
loudly otherwise (k[x]/(x²) = the negative test). K₀ facts: [S] = CᵀC⁻¹,
Coxeter matrix = −CᵀC⁻¹ (conjugate to the paper's −C⁻¹Cᵀ; same char poly).
Not feasible (honest scope): classifying D^b indecomposables for wild
algebras; *deciding* derived equivalence (invariants are necessary-only).

**Surfaces + categorical glue.** Triangulation → (Q(T), W(T)) (Fomin–Shapiro–
Thurston 2008; Labardini 2009) is purely combinatorial; Jacobian algebra
finite-dim certified (always Jacobian-finite for nonempty boundary; closed
punctured per-instance); flip ↔ DWZ mutation certifiable per instance. Gentle
↔ dissection models (Opper–Plamondon–Schroll 2018, Baur–Coelho Simões 2021).
**AG-invariant (AAG 2008): computable, derived-invariant, NOT complete** —
must be labeled honestly. Butler–Ringel string/band classification fully
algorithmic. Igusa–Todorov φ/ψ: finite K₀+syzygy algorithm, truncated-path
closed forms as oracles (Barrios–Mata 2019). QPA white space: AG-invariant,
string/band enumerator, quasi-hereditary (Δ/∇/test/Ringel dual), recollements,
support-τ-tilting enumeration. QPA parity (cross-oracle, expect agreement):
Hom kernels/cokernels/images, pushout/pullback, approximations, DTr/TrD,
`IsGentleAlgebra`/`IsSpecialBiserialAlgebra`.

**Koszulity (local audit).** Already computable: `Algebra.ext_algebra(top)` →
`YonedaPresentation.koszul` three-valued verdict (`modules/koszul.py`). **Not
exposed in any no-code tier** — a metagoal-1 debt, fixed in P38.

## 3. Mechanics

- **Trunk:** `dev`. Every subplan branches `plan-NN-<slug>` off `dev`, merges
  back to `dev` green. `dev` → `main` only at the release gate (P50). Docs
  deploy stays main-only (a2af604). Hotfixes to published 0.1.0 go main-first
  as 0.1.x and merge down into `dev`.
- **Versioning:** `dev` carries 0.1.0 until P50 bumps to 0.2.0 (single bump at
  the gate, matching the v0.1.0 release pattern).
- **Standing rules — per plan, at its own merge, never deferred to P50:**
  oracle-first acceptance + `docs/verification.md` update (Plan 22), a
  GUI/no-code story (metagoal 1), Plan-32 oracle-class markers
  (`oracle_literature` / `oracle_crossengine` / `oracle_selfcert` / `qpa` /
  new `m2`), honest semi-decision contracts, citations in
  `citations/references.bib`, conventional commits, green at every commit.

## 4. Wave map

Plans within a wave are independent (parallelizable, e.g. worktrees); arrows
are real dependencies.

```
W1  P36 Macaulay2 oracle   P37 C1 categorical glue   P38 C2 forms/Coxeter/Koszul-GUI
         │                    │        │                     │
W2  (m2 class ready)      P39 complexes/cones/hyper-Ext   P40 C6 homdims   P41 C3 AR completion
                              │            │                                   │
W3  P42 spectral sequences ◄──┤        P43 derived category ◄─ P44 C7 constructions
                              │            (End(T) quiver form needs P44)      │
W4  P45 C4 τ-tilting ◄─(P37,P38,P41)   P46 C5 gentle/string ◄─P38   P47 quasi-hereditary/recollements ◄─(P37,P44)
W5  P48 surfaces ◄─(P44 Jacobian, P46 dissections)          P49 C8 geometry ◄─P38
W6  P50 integration sweep + v0.2.0 release gate
```

Critical path: P37 → P39 → {P42, P43}. P36, P38, P40 are off-path slack
absorbers. Axis landing: M2 = P36, spectral sequences = P42, derived = P43,
surfaces = P48, category theory = P37+P47, Coxeter polynomial = P38.

### P39 — Complexes, chain maps, cones, hyper-Ext (W2; needs P37)

**Delivered (2026-08-05, branch `plan-39-complexes`).** `modules/complexes.py`:
validated bounded `ChainComplex`/`ChainMap` (homological `d_n: C_n → C_{n-1}`,

### P42 — Spectral-sequence engine + presets (W3; needs P39)

Core: bounded filtered complex → exact pages E_r = Z_r/(Z_{r−1}+B_{r−1}) on

## 6. Risks & honest-scope ledger

Stated on the verification page as each plan lands:

- Deciding derived equivalence is not algorithmic — P43 ships verifiers and
  necessary-condition invariants, never a decider.
- AR knitting (P41) and τ-tilting BFS (P45) are semi-decisions: complete iff
  finite; loud budget caps otherwise.
- M2 cannot see multi-vertex algebras or Hochschild anything (P36 scope note);
  `AssociativeAlgebras` is upstream-unstable — pin the version.
- Grothendieck-SS acyclicity (P42) is a per-instance hypothesis check with a
  loud refusal path.
- AG-invariant (P46/P48) is not a complete derived invariant — never claim
  completeness.
- Wild classification (of modules or of D^b objects) is out of scope; string
  enumeration only for the special-biserial class.
- Completed Jacobian ideals (P48) handled only in the certified
  Jacobian-finite case.
- Serre functor / AR triangles / τ_{D^b} refuse loudly at infinite gl.dim.
