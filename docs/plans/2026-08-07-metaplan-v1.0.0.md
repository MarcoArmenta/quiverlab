## 1. Scope decisions

1. **Scope = the whole adjudicated record set** (R1–R37, tiers α–δ of the
   research doc §9), partitioned into 29 implementation plans P51–P79 plus
   the P80 integration/release gate. Records grouped only where the critics'
   dependency notes make one worker's scope coherent (noted per card).
2. **GUI incorporation is in-plan, not deferred by default:** every plan that
   adds a user-visible computation ships its webapp/GUI compute kind(s) in
   the same plan (schema guard, canonical-key stability, both runners —
   `quiverlab/hpc/spec.py` + the Pyodide twin `docs/gui/runner.py` — i18n
   ×4, picker rows, report rendering, citations). A plan may defer GUI
   wiring ONLY by writing an explicit entry in the GUI-deferral ledger
   (`docs/plans/DEEPER-ENGINES-BACKLOG.md`) that P80 reconciles; silent
   deferral is a plan-review defect.
3. **Honest-scope boundaries from the research doc are contractual:** every
   scope limit (char-0, rep-finite, brick-finite, algebraically-closed,
   bounded-window…) becomes a loud typed refusal, never a silent gap.
4. **Research-grade tail bounded:** R31 (Amiot–Keller cluster categories, XL)
   ships as a certified verifier-grade slice — scope fixed at its plan spec,
   not open-ended.
5. **Reference re-verification at spec time** (standing rule of the research
   doc): each plan writer re-verifies its record's citations; the two flagged
   attributions (R7's arXiv:2409.00945; R2's verbatim 2603.04834 formulas)
   block their plans until resolved.

## 5. Plan cards

Every card implicitly includes: loud typed refusals at the record's scope
boundaries; oracles on the verification page with Plan-32 class markers;
QPA/M2 crosschecks wherever those systems implement the feature (honest-scope
entry where they don't); GUI/webapp kind(s) or an explicit ledger deferral;
citations added to `references.bib` (BibTeX-verified) and surfaced in
results.

**P51 — bracket beyond the bar window (R1, size L).**
`[-,-]` natively on CS/minimal/Bardzell via homotopy liftings (Volkov
1610.05741; Oke 2103.12331; Witherspoon GSM 204) — the finite linear solve +
`reduce_mod_nullspace` canonicalization, same pattern as the Plan-20 Δ. New
content: past-window + any exact Domain (the Plan-35 bracket is GF(p),
window-bounded). Oracles: in-window ≡ transported (cross-engine),
antisymmetry/Jacobi/Leibniz-compatibility (self-cert), 2103.12331
Koszul-quiver tables, k[x]/(x^n) zero-entries. GUI: `gerstenhaber_brackets`
gains the past-window/off-GF(p) route + provenance gloss.

**P52 — HH with bimodule coefficients + relative HH (R4, size M).**
HH•(A,M)/HH_•(A,M) for any f.d. A-bimodule M (twisted _1A_σ, D(A), A/soc);
relative HH•(A|B) via the relative bar resolution. Engine: swap the
coefficient in Hom_{A^e}(P•,−) across bar/minimal/CS. Refs:
Chaparro–Schroll–Solotar 1811.02211; Lindell–Rubio y Degrassi 2411.03080.
Prerequisite of P54/P72/P74 (+R9 route). Oracles: M=A ≡ ordinary HH
degreewise (cross-engine); gentle HH¹-with-coefficients pins from 1811.02211.
GUI: coefficient picker on the hochschild kinds (M from the no-code module
surface, side-pair aware).

**P53 — homological invariants II (R23+R24, size M total).**
(a) φdim(A)/ψdim(A) as algebra invariants — rep-finite exhaustive sup over
knitted indecomposables (⊕-of-all via add-monotonicity), certified lower
bounds otherwise; standing chain self-cert findim ≤ φdim ≤ ψdim ≤ gldim;
φ-spectrum/gaps (Barrios–Mata–Rama 1810.12112); LIT certificate families
with proof-carrying findim bounds (Bravo–Lanzilotta–Mendoza–Vivero
2002.07866). (b) fractional CY dimension (m,n) of self-injective A: Ω^m ≅
ν-twist periodicity in the stable category; refs pinned at plan time
(Keller-school; Π(A_n) known values as oracles). GUI: `homdim_profile`
extension + `fractional_cy` kind.

**P54 — BV operator (R2, size M; needs P52).**
Δ: HH^n → HH^{n-1} on Frobenius/self-injective A by transporting Connes B
through σ-twisted duality; bracket recovered from Δ, checked against the
independent bracket (7-term BV axioms self-cert). Implementation picks its
hypothesis DELIBERATELY: LZZ 1405.5325 (semisimple ν) vs Volkov 1405.5155
(ord(ν) coprime to char) vs BIKLZ 2603.04834 (self-injective Nakayama, no
semisimplicity) — the plan doc records which and why; the 2603.04834 kZ₁/J^N
pins transcribed verbatim with equation numbers BEFORE tests use them.
Oracles: Δ²=0; bracket-from-Δ ≡ independent; Tradler on k[x,y]/(x²,y²)
([4,4,5,6] pin); QuantumCI ties. GUI: `bv_operator` kind on the hochschild
theme.

**P55 — left/right parts substrate (R15, size M).**
L_A/R_A via closed-under-predecessors pd/id sweep on the knitted AR quiver
(rep-finite, loud otherwise); Ext-injectives of add L_A; support algebras
A_λ/A_ρ + the products-of-tilted theorem as self-cert (verified by P60).
Refs: Assem–Coelho–Trepode 2004; ACLV 1102.1188. GUI: `left_right_parts`
kind (module-category atlas block).

**P56 — π₁(Q,I) + strong simple connectedness (R14+R16, size M+M).**
(a) Combinatorial π₁(Q,I) (walks mod relation-homotopy over a spanning
tree), abelianization by exact SNF, Hom(π₁,k⁺) ↪ HH¹ cross-check; honest
decidability: π₁^{ab} always, "simply connected" only via decidable
sufficient criteria; intrinsic π₁ refused loudly. CORRECTED oracle:
commutative square WITH relation ⇒ π₁=1, ℤ without. (b) The separation
condition for triangular A (rad P_x support decomposition over non-predecessor
components) — pure combinatorics + Krull–Schmidt, witness on failure; gates
P62. Refs: Assem–de la Peña 1996; CRS 0706.2491/1010.6296/0906.3069; Le Meur
math/0503302; Briggs–Rubio y Degrassi 2109.03704; Skowroński 1993. GUI:
`fundamental_group` + `simply_connected` kinds.

**P57 — Liu degrees + the radical filtration (R21+R37, size M+M).**
Left/right degrees of irreducible maps, sectional paths,
postprojective/preinjective/regular partition, generalized-standard flags,
directing modules, rep-directed recognizer; then the Liu–Chaio program:
rad^n layer dims via mesh-composites, nilpotency index of rad(mod A)
(rep-finite), rad^∞ = 0 ⇔ rep-finite gate, (rad^∞)²=0 ⇒ finite type + the
CMMS/Kerner–Skowroński taxonomy as class oracles; bounded-window rad^n on
rep-infinite input, honestly labeled. Refs: Liu JLMS 1992/93; Chaio school
(ART 2018/2019/2023, 1704.03933); CMMS 1994/96. GUI: `radical_filtration` +
`ar_invariants` kinds.

**P58 — Coxeter spectral analysis (R20, size S–M).**
Cyclotomic test (exact ℤ[x] factorization + Φ_n recognition); Mahler measure
+ spectral radius as certified algebraic numbers (minimal polynomial +
rational isolating interval — sympy CRootOf/Sturm, never a float); Lehmer
dichotomy reported per-class only. Refs: de la Peña 1310.1910/1310.1557;
de la Peña–Takane 1990. Oracles: kA₂ χ=Φ₃; 3-Kronecker x²−7x+1; T_{2,3,7} =
Lehmer degree-10. GUI: extend `derived_fingerprint`/Coxeter block.

**P59 — recognizer batteries (R34+R35, size M+S–M).**
(a) Homological string test: rep-finite A is string ⇔ every extension of
indecomposables has middle term with ≤ 2 summands (arbitrary Ext¹ classes —
NOT just AR sequences; Suárez-Álvarez 2105.02948); discriminating battery vs
is_string. (b) Toupie recognizer + closed-form HH oracle family + HH¹ ⊇ sl_a
(char-0 only; ALS 1803.10310 journal version). GUI: recognizer panel rows.

**P60 — tilted-algebra recognizer (R17, size M; needs P55).**

Oracles: hereditary ⇒ tilted; kZ₃/J² ⇒ not; cluster-tilted A₃ ⇒ not. GUI:

**P61 — quasi-tilted/shod/laura/ada ladder (R18, size M; needs P55).**
