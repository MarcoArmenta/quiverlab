The JSON record

This page pairs with a machine-readable record, trace.json (the “Report data (JSON)” download). Its structure:

  • quiverlab_trace_schema — integer version of this format;
  • title — the computation this record traces;
  • references — the same bibliography as the References section, as [key, formatted] pairs;
  • events — the complete ordered stream of worked steps. Each event is an object with a type field (e.g. dispatch, resolution_term, rank_step, module_term, module_differential, ext_degree, step_note, result_dims) plus that step's exact data — every matrix entry is exact (integers / rationals as strings), never floating point.

The computation's summary results (one block per requested invariant, with dimensions, matrices, and citation keys) live in the separate result.json deliverable. HTML and JSON are the only report formats — this page is the complete human-readable record.
